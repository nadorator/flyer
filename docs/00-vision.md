# Flyer — Vision produit

> **Flyer** aide les photographes événementiels à remplir leurs séances en reprenant la main sur leur communication : création d'event, flyers et contenus générés par IA, publication multi-plateforme, kit partenaire et CRM léger — le tout depuis leur téléphone.

## 1. Le problème terrain

Camille est photographe animalière. Plusieurs fois par mois, elle installe son studio mobile dans une animalerie (Zooplus, Maxi Zoo…) pour une journée de séances photo d'animaux de compagnie.

Le deal avec le magasin est toujours le même : **le magasin fait la pub et prend les réservations**, la photographe apporte le matériel et le savoir-faire.

Dans les faits, la veille au soir, quand elle appelle le magasin :

- aucune affiche n'a été imprimée ;
- rien n'a été posté sur la page Facebook locale du magasin ;
- 2 créneaux sur 30 sont réservés ;
- l'équipe en magasin « n'a pas eu le temps ».

Conséquences :

| Pour la photographe | Pour le magasin | Pour les clients |
|---|---|---|
| Journée sous-remplie, CA imprévisible | Animation ratée, image dégradée | Ne découvrent l'event que trop tard (ou jamais) |
| 3 h de communication « à l'arrache » la veille | Pas de visuel prêt à relayer | Ne savent pas où/comment réserver |
| Dépendance totale à un partenaire non fiable | Pas de suivi des réservations | Pas de rappel |

**Insight clé** : le partenaire ne fera pas la pub. La photographe doit pouvoir **tout faire elle-même en 15 minutes**, et **donner au magasin un kit prêt à l'emploi** qui ne lui demande aucun effort.

## 2. Proposition de valeur

> **« Crée ton event, Flyer s'occupe de le faire connaître. »**

1. **Un event en 5 minutes** : dates, horaires, lieu, enseigne partenaire, tarifs, lien de réservation, à partir du profil entreprise déjà renseigné.
2. **Des flyers et textes générés par IA**, déclinés automatiquement pour chaque plateforme (Instagram, Facebook, TikTok, LinkedIn, Google Business, groupes locaux, page magasin, affiche A4).
3. **Une checklist des besoins par plateforme** (photo, vidéo, audio, texte) avec statut : rien n'est oublié, l'IA comble les manques.
4. **Publication en 1 clic** sur les plateformes connectées, ou partage natif en fallback.
5. **Un kit partenaire** (affiche imprimable + posts prêts) envoyé au magasin par simple lien.
6. **Une page publique d'event** avec bouton de réservation : les contacts arrivent directement dans le CRM.
7. **Un CRM léger** (clients, animaux, historique, consentement RGPD) synchronisable avec Salesforce, Odoo ou CSV.

| Segment | Description | Priorité |
|---|---|---|
| **Photographes animaliers en magasin** | Indépendants, 1 à 4 events/mois en animalerie, dépendants du magasin pour la pub | ⭐⭐⭐ Cœur de cible (persona Camille) |
| **Photographes événementiels multi-salons** | Famille, mariage, salons, studios éphémères, clientèle déjà constituée | ⭐⭐ Extension naturelle (persona Marc) |

| **Clients finaux** | Propriétaires d'animaux, familles | ⭐ Via page publique uniquement (persona Léa) |

## 4. Principes produit

1. **Mobile-first, pouce-first** : tout se fait sur téléphone, entre deux séances, en moins de 15 minutes.
2. **L'IA propose, la photographe dispose** : plusieurs propositions, édition facile, jamais de publication automatique sans validation explicite.
3. **Zéro dépendance au partenaire** : chaque fonctionnalité doit fonctionner même si le magasin ne fait rien ; le kit partenaire est un bonus, pas un prérequis.
4. **Rien n'est oublié** : la matrice plateforme × besoin rend visible ce qui manque.
5. **Mesurer pour apprendre** : chaque fonctionnalité émet un événement analytique lié à une hypothèse Lean UX.
6. **RGPD by design** : consentement explicite, export/suppression, données hébergées en UE, clés API uniquement côté serveur.
7. **Gratuit pour les ambassadeurs** : les codes partenaires déverrouillent tout, en échange de feedback.

## 5. Ce que Flyer n'est pas (pour l'instant)

- Pas un outil de retouche photo.
- Pas une place de marché de photographes.
- Pas un système de réservation complet (on pointe vers le lien de réservation existant de la photographe, ou une page publique simple).
- Pas un CRM complet : un carnet de clients léger, synchronisable avec les vrais CRM.

## 6. Mesure du succès (12 mois)

| Indicateur | Cible |
|---|---|
| Taux de remplissage moyen des créneaux d'un event publié via Flyer | ≥ 70 % |
| Temps médian « création event → première publication » | ≤ 15 min |
| Plateformes publiées par event | ≥ 3 |
| Kits partenaires ouverts par le magasin | ≥ 50 % |
| Conversion Gratuit → Pro | ≥ 8 % |
| Rétention à 3 mois | ≥ 40 % |
